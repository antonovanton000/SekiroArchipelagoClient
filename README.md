# Sekiro Archipelago Client
**Alpha Version **

This is an early alpha release of the Sekiro Archipelago Client.

**Requirements**

Install .NET 10 Runtime

A clean installation of Sekiro: Shadows Die Twice

**Installation**

Download and extract the release files.

Place the randomizerAP folder in your Sekiro game directory (the same folder where sekiro.exe is located).

Run SekiroAPClient.exe.
